Tailscale only

Connect a coding agent to VK

This page serves the VK CLI, the Veritas Kanban agent skill, and platform installers directly from the board host. Port 3001 is HTTP because Tailscale provides the encrypted transport.

First create a scoped agent identity.

Sign in to Veritas Kanban, open Settings → Security, and use Remote agent credentials. The key is shown once. Transfer it to the station through a private channel; never put it in a task or repository.

Install

Linux x86-64

curl -fsSLo /tmp/install-vk.sh http://100.115.155.120:3001/remote-agent/install.sh
chmod +x /tmp/install-vk.sh
/tmp/install-vk.sh --agent-id 'station-agent-id'

The installer places vk in ~/.local/bin and installs the skill for Codex and shared agent runners.

Windows x86-64

$installer = "$env:TEMP\install-vk.ps1"
irm http://100.115.155.120:3001/remote-agent/install.ps1 -OutFile $installer
& $installer -AgentId 'station-agent-id'

The installer places vk.exe in %USERPROFILE%\.local\bin and updates the user PATH.

Agent-readable setup

Give an agent http://100.115.155.120:3001/llms.txt. It contains the complete identity request, install, configuration, smoke-test, and work-tracking flow.
